# Tech Innovation News Show

An automated technology news platform that gathers daily tech news, generates audio episodes and transcripts, and provides interactive Q&A and analytics.

## Project Scope
- **Phase 1:** Project initialization, starter frontend & backend health check.
- **Phase 2:** Database & data modeling (PostgreSQL).
- **Phase 3:** News ingestion pipeline.
- **Phase 4:** AI summarization, categorization, & script generation.
- **Phase 5:** Audio generation & playback (Text-to-Speech).
- **Phase 6:** "Ask This Episode" (RAG-based Q&A).
- **Phase 7:** News analytics & trends dashboard.
- **Phase 8:** Deployment (Vercel, Render/Railway, Neon).
